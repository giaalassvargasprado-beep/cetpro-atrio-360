# CETPRO ATRIO · Recorrido 360°

Recorrido virtual del proyecto CETPRO ATRIO (Santa María, Carabayllo, Lima Norte): mirador del atrio, plaza, restaurante y auditorio, de día y de noche.

Abre la página en el celular, ponlo en horizontal y muévelo para mirar alrededor.

Modelo: Revit · Render: Blender Cycles · Cielos: Poly Haven (CC0) · Visor: Pannellum (MIT).
